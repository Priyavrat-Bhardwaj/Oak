## About OAK

OAK is a furniture and interior design e-commerce concept built around the idea that great digital experiences should be as thoughtfully designed as the spaces they represent.

Combining editorial-inspired aesthetics, immersive product presentation, refined interactions, and a warm contemporary visual identity, OAK aims to transform ordinary online furniture shopping into an engaging digital experience.

Beyond its visual identity, the project explores how principles of human visual perception can influence interface design, improve navigation, and create more intuitive user experiences.

## Design Philosophy

OAK brings together three central ideas:

- **Timeless aesthetics** — A warm, minimal and editorial-inspired visual language.
- **Thoughtful interactions** — Purposeful transitions, intuitive navigation and carefully designed interface details.
- **Perceptual design** — Applying principles of visual grouping, hierarchy and human perception to improve usability.

The visual direction combines natural materials, architectural imagery, sophisticated typography, subtle glassmorphism and restrained motion.

## Gestalt Principles

The interface explores all eight Gestalt principles:

| Principle | Design application |
|---|---|
| Proximity | Grouping related product information |
| Similarity | Consistent product cards and UI elements |
| Continuity | Creating clear visual flow and navigation |
| Closure | Using incomplete forms and visual patterns |
| Figure–Ground | Establishing contrast and visual depth |
| Common Region | Grouping related content in shared containers |
| Common Fate | Coordinating the movement of related elements |
| Focal Point | Directing attention through visual hierarchy |

These principles form an important part of the project's design foundation and user experience strategy.

## Getting Started

### Prerequisites

- Node.js
- npm or Bun

### Installation

Clone the repository:

```bash
git clone REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd repository_name
```

Install dependencies:

```bash
npm install
```

Or, if using Bun:

```bash
bun install
```

### Run locally

```bash
npm run dev
```

Open the local development URL displayed in your terminal.

## Project Purpose

OAK was developed as part of a Design Foundation for Engineers assignment.

The project investigates how visual design principles can move beyond theory and become practical tools for creating meaningful digital interfaces.

Its objective is to demonstrate that good design is not simply about appearance; it is about understanding how people perceive, interpret and interact with information.
